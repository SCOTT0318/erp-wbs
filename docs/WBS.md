# TempChain ERP WBS

기준일: 2026-09-21  
전체 진행률: **3%**

## 산정 원칙

- 전체 ERP 구축 범위를 100%로 두고 작업 패키지별 관리 가중치를 배분합니다.
- 현재 진행률 3%는 마스터가 지정한 프로젝트 기준값이며 `js/wbs-data.js`의 `baselineProgress`로 관리합니다.
- 완료 항목은 현재 저장소의 소스와 문서에서 구현 기반을 확인한 항목이며 운영 인수 완료를 뜻하지 않습니다.
- 향후 범위 97%는 요구사항 확정 전의 관리 기준입니다. 범위·담당자·일정이 확정되면 가중치와 작업을 다시 기준화합니다.
- 금융·회계 업무는 구축 범위에서 제외합니다.
- 미래 기능을 미리 확정하지 않고 생산부 → 사업부 → 기술개발부 순서로 한 부서씩 조사·합의·설계·구현·검증합니다.
- 비밀번호, 토큰, 환경 파일 내용, 실제 계정 및 운영 데이터는 WBS에 포함하지 않습니다.

## 앞으로 해야 할 일 — 36개, 97%

생산부·사업부·기술개발부는 각각 아래 12단계로 관리합니다. 각 부서의 세부 기능은 요구사항 검토 전에 확정하지 않습니다.

1. 업무 착수 범위 확정
2. 현행 업무 흐름 조사
3. 문제와 개선 기회 수집
4. 데이터·입출력 현황 정리
5. 요구사항 초안 작성
6. 요구사항 검토와 우선순위
7. 목표 업무 프로세스 설계
8. 역할·권한·승인 설계
9. 화면·API·데이터 설계
10. 확정 범위 구현
11. 통합 검증과 사용자 확인
12. 보완·인수·다음 단계 판단

## 권장 진행 순서

1. 생산부 12단계를 완료합니다.
2. 생산부 인수 후 사업부 12단계를 진행합니다.
3. 사업부 인수 후 기술개발부 12단계를 진행합니다.

항목별 설명·산출물·관리 가중치의 단일 원본은 [`js/wbs-data.js`](../js/wbs-data.js)이며, 현황판은 [index.html](../index.html)에서 확인합니다.
