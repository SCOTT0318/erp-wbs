## 현재 상태와 산정 원칙

- 전체 ERP 기준 진행률은 전일 **5%**에서 오늘 **6%**로 갱신합니다. 생산부 업무 개선·구매 권한 분리·인증 정책·서버 배포 확인을 반영한 **1%p의 보수적 관리 추정치**이며 항목 수나 신규 가중치의 합계가 아닙니다. 기존 기준선 **3%**와 완료 기반 가중치는 보존합니다.
- 기존 구현 기반 **18개**는 `완료 기반`, 부서 업무 **65개**와 공통 기반·운영 **8개**, 합계 **73개**는 `진행 중`, 공통 기반·운영 **22개**는 `예정`입니다. 전체 WBS **113개**, 업무 영역 **19개**는 유지합니다.
- 신규 수용 기준은 현업 확인이 남은 **초안**입니다. 항목 수를 진행률로 환산하지 않으며 잔여 **94%**를 임의 배분하지 않습니다. 생산부 완성을 우선하되 항목별 담당자·일정·완료일·가중치는 확정 전입니다.
- 기존 자재·재고, 직렬화 컨테이너, 생산지시 기능은 `기반 완료`입니다. 아래 신규 작업의 부서 간 연계, 자동 반영, 현업 인수나 운영 배포 완료를 의미하지 않습니다.
- 금융·회계 업무는 범위에서 제외합니다. 비밀번호, 토큰, 환경 파일 내용, 실제 계정과 운영 데이터는 WBS에 넣지 않습니다.
