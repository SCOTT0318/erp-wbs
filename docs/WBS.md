### 생산부

1. **생산관리:** 사업부 의뢰 접수, 사양·자재·설비 확인, 생산 계획·작업지시, 실적·불량·재작업 정산, 결과 회신.
2. **자재관리:** 자재 마스터, 창고·위치, 안전재고, 로트·유효기간, 현재고·예약·가용 수량 대조.
3. **자재 입출고 관리:** 입고 검수, 생산 출고·예약, 반납·이동·역거래, 실사·조정 승인, 수불원장 대사.
4. **완제품 관리:** 제품 마스터·식별, 검사·격리·가용 판정, 위치별 재고 상태.
5. **완제품 입출고 관리:** 생산 완료품 입고, 출하 예약·피킹, 실출고·인계, 반품·재입고, 실사·원장 대사.
6. **컨테이너 출고·입고 관리:** 개체별 가용성, 예약·상차·출고, 회수·점검, 수리·재가용 판정.

## 부서 간 연결과 결정 대기

- 사업부 **생산 의뢰 → 생산부 생산 계획·지시·실적 → 사업부 결과 회신**.
- 사업부 **컨테이너 출고 신청 → 생산부 가용성 확인·개체 예약·출고 → 사업부 실출고·회수 확인**.
- 사업부 **구매신청 → 생산부 자재 입고**의 수량·상태 대조.
- 챔버와 VIP 샘플은 독립 업무로 분리하며 예약 선택 연결·상호 처리 제한을 제거했습니다. 기술개발부 시험 결과와 완제품 출하 판정 연계는 **검토 후보**이며 자동 차단·자동 재고 반영은 업무 규칙 확인 후 결정합니다.
- 공통 ID, 상태 전이, 승인권자, 정정·역거래, 중복·동시 처리, 부서 간 조회 범위와 알림 규칙을 먼저 합의합니다.
