# TempChain ERP WBS

기존 진행률 기준일: **2026-09-21**

요청 범위 정리일: **2026-09-23**

확인된 전체 진행률: **3%**

## 현재 상태와 산정 원칙

- 전체 ERP 기준 진행률은 기존 마스터 기준선 **3%**를 유지합니다. 기존 구현 기반 18개 항목의 가중치 합계가 3%입니다.
- 사용자 요청을 반영한 신규 상세 작업 **95개**는 모두 `예정`입니다. 생산부 33개, 사업부 20개, 기술개발부 12개, 공통 기반·운영 30개입니다. 전체 WBS는 **113개**, 업무 영역은 **19개**입니다.
- 신규 항목은 요구사항·수용 기준의 **초안**입니다. 항목 수를 진행률로 환산하지 않으며, 잔여 97%를 항목별로 임의 배분하지 않습니다. 일정·담당자·우선순위·완료일도 확정 전입니다.
- 기존 자재·재고, 직렬화 컨테이너, 생산지시 기능은 `기반 완료`입니다. 아래 신규 작업의 부서 간 연계, 자동 반영, 현업 인수나 운영 배포 완료를 의미하지 않습니다.
- 금융·회계 업무는 범위에서 제외합니다. 비밀번호, 토큰, 환경 파일 내용, 실제 계정과 운영 데이터는 WBS에 넣지 않습니다.

### 생산부

1. **생산관리:** 사업부 의뢰 접수, 사양·자재·설비 확인, 생산 계획·작업지시, 실적·불량·재작업 정산, 결과 회신.
2. **자재관리:** 자재 마스터, 창고·위치, 안전재고, 로트·유효기간, 현재고·예약·가용 수량 대조.
3. **자재 입출고 관리:** 입고 검수, 생산 출고·예약, 반납·이동·역거래, 실사·조정 승인, 수불원장 대사.
4. **완제품 관리:** 제품 마스터·식별, 검사·격리·가용 판정, 위치별 재고 상태.
5. **완제품 입출고 관리:** 생산 완료품 입고, 출하 예약·피킹, 실출고·인계, 반품·재입고, 실사·원장 대사.
6. **컨테이너 출고·입고 관리:** 개체별 가용성, 예약·상차·출고, 회수·점검, 수리·재가용 판정.
7. **출고 신청:** 신청·중복 확인, 승인·반려, 재고 할당, 부분 출고·취소·완료 결과 회신.

### 사업부

1. **구매신청 관리:** 품목·수량·희망 납기 등록, 견적 참고, 승인·반려·보완, 발주·입고 상태 대조.
2. **컨테이너 출고 신청:** 고객 요청, 생산부 가용성 회신, 승인 후 예약·출고 연결, 개체별 실출고·회수 상태 확인.
3. **입출고 신청서 Excel·PDF 자동 생성:** 표준 템플릿·필드 매핑, 승인 상태와 버전 표시, 미리보기, 파일 생성, 다운로드 권한·발행 감사, 정정·재발행.
4. **생산 의뢰서:** 제품·규격·수량·납기 작성, 승인 후 생산부 전달, 가능일 회신, 변경·재승인, 지시·실적·완료 추적.

### 기술개발부

1. **완제품 테스트 챔버 스케줄:** 장비·용량·교정 정보, 예약 충돌, 승인·연장·가동중지, 시험 실행·이상 기록, 가동률.
2. **VIP 샘플 추적 테스트:** 고유 ID, 보관·이동·인수인계, 시험 조건·챔버 연계, 결과·성적서, 재시험, 반환·폐기·접근 감사.

## 부서 간 연결과 결정 대기

- 사업부 **생산 의뢰 → 생산부 생산 계획·지시·실적 → 사업부 결과 회신**.
- 사업부 **컨테이너 출고 신청 → 생산부 가용성 확인·개체 예약·출고 → 사업부 실출고·회수 확인**.
- 사업부 **구매신청 → 생산부 자재 입고**의 수량·상태 대조.
- 기술개발부 시험 결과와 완제품 출하 판정의 연결은 **검토 후보**이며, 자동 차단·자동 재고 반영 등은 업무 규칙 확인 후 결정합니다.
- 공통 ID, 상태 전이, 승인권자, 정정·역거래, 중복·동시 처리, 부서 간 조회 범위와 알림 규칙을 먼저 합의합니다.

## 보안부터 운영 최적화까지

1. **업무·권한 정의:** 현행 서식과 예외 조사, 데이터 분류, 부서별 조회·작성·승인·다운로드 권한표.
2. **설계·구현:** 화면·API·DB·원장·파일·문서 생성, 이관과 변경 이력. 기존 기능과의 경계 확인.
3. **보안·품질 검증:** 세션·입력·첨부·출력 보호, 취약점 점검, 무권한 접근, 동시성·중복·취소·복원 회귀와 현업 확인.
4. **서버 배포·전환:** PC 웹·API·독립 DB 및 NAS 프록시·TLS 경계 확인, 환경·비밀 관리, 백업, 스테이징, 운영 배포, 헬스·업무 시나리오, 롤백 검증. 실제 서버에 적용·접속을 검증하기 전에는 완료로 표시하지 않습니다.
5. **성능·운영:** 동시 사용자·응답 시간·대량 출력 목표 합의, API·DB·웹·문서 생성 병목 측정과 개선, 부하 재시험, 로그·지표·알림·백업 상태 관측 및 운영 인수.
