# ERP WBS 관리 안내

기존 진행률 기준일: 2026-09-21

요청 범위 정리일: 2026-09-23

2026-09-29 현재 전체 진행률: **5%**

이 화면은 ERP 실제 업무 시스템이 아니라 **정적 WBS 계획·현황 페이지**입니다. `대시보드`는 범위·연계·단계를 요약하고, `상세사항`은 항목별 설명·산출물·수용 기준을 보여줍니다. 검색과 영역·상태 필터를 제공합니다.

## 파일 구조

- `index.html`: 두 탭의 구조와 고정 안내 문구
- `css/wbs.css`: 반응형·인쇄 스타일
- `js/wbs-data.js`: 완료 기반, 부서별 신규 작업, 연결 흐름의 단일 원본
- `js/wbs.js`: 요약 수치·탭·검색·필터·접기/펼치기 렌더링
- `docs/WBS.md`: 산정 원칙과 범위 요약

외부 라이브러리나 백엔드 없이 `index.html`을 직접 열어 사용할 수 있습니다. 이 페이지에서 ERP 업무 데이터를 입력·수정하거나 서버에 배포하지 않습니다.

## 산정·상태 규칙

- 기존 전사 ERP 진행률 3%를 `baselineProgress`로 보존합니다. 기존 완료 기반 18개의 가중치 합계도 3%입니다. 2026-09-29의 `currentProgress`는 마스터 요청과 확인된 구현 진척을 반영한 **5%** 관리 추정치입니다.
- 신규 95개는 상세 업무 초안입니다. 이 중 생산부·사업부·기술개발부 65개는 코드 구현 대응과 격리 검증 근거가 있어 `in_progress`, 공통 기반·운영 30개는 `planned`입니다. 항목 수는 진행률이 아니며 잔여 95%는 **미배분** 상태입니다.
- `done`은 기존 구현 기반이 소스·문서에서 확인됐다는 의미입니다. `in_progress`는 2026-09-29 ERP 커밋 4786021과 부서별 대응표에서 구현이 확인됐으나 현업 수용 기준은 남았다는 의미입니다. 두 상태 모두 운영 인수·최신 환경 배포 완료를 뜻하지 않습니다.
- 현업 확인 전에는 신규 기능의 담당자·일정·우선순위·완료일·가중치를 추정하지 않습니다. 생산부·사업부·기술개발부의 연결 규칙은 해당 부서와 함께 확정합니다.
- 상태를 바꿀 때는 코드·테스트·실사용 확인·서버 접속 등 해당 항목에 맞는 근거를 기록하고, 페이지와 문서를 함께 갱신합니다. 이번 근거와 남은 검증은 [WBS 작업 기록](WBS.md#2026-09-29-erp-작업-반영)에 정리했습니다.
- 금융·회계는 범위에서 제외합니다. 비밀번호·토큰·환경 파일·실제 계정·운영 데이터는 페이지에 포함하지 않습니다.
