# ERP WBS 관리 안내

기준일: 2026-09-21  
현재 전체 진행률: **3%**

현재 WBS는 마스터가 지정한 3%를 프로젝트 기준선으로 사용합니다. 기존의 기능 20개 기준 78%는 제한된 기능 목록에 대한 별도 추정치였으며, 전사 ERP 전체 구축 진행률로 사용하지 않습니다.

전체 진행률은 `js/wbs-data.js`의 `baselineProgress`를 코드에서 직접 변경합니다. 화면에서 입력하거나 브라우저에 자동 저장하지 않습니다.

## 파일 구조

- `index.html`: 정적 WBS 대시보드 진입점
- `css/wbs.css`: 반응형 화면과 인쇄 스타일
- `js/wbs-data.js`: 작업 패키지, 가중치, 산출물 원본
- `js/wbs.js`: 현재 날짜·진행률·검색·상태 필터와 화면 렌더링
- `docs/WBS.md`: 산정 원칙과 전체 작업 목록

외부 라이브러리나 서버 없이 `index.html`을 직접 열어 사용할 수 있습니다. 화면은 전체·완료·예정 상태 필터와 업무명·설명·산출물 검색을 제공합니다.

## 산정 규칙

- 전체 구축 범위의 가중치 합은 100%입니다.
- 현재 구현 기반 18개 항목의 가중치 합은 3%입니다.
- 향후 작업 36개 항목의 가중치 합은 97%입니다.
- 금융·회계는 범위에서 제외합니다.
- 각 부서는 착수 범위, 현행 조사, 문제·데이터 정리, 요구사항 확정, 프로세스·권한·기술 설계, 구현, 검증, 인수의 12단계로 진행합니다.
- 생산부를 먼저 끝낸 뒤 사업부, 기술개발부 순서로 진행합니다.
- 각 부서의 세부 기능은 해당 부서 회의와 요구사항 확인 전에는 확정하지 않습니다.
- 완료 표시는 저장소에서 구현 기반이 확인됐다는 의미이며 운영 인수나 전사 배포 완료를 뜻하지 않습니다.
- 요구사항, 담당자, 일정과 완료 조건이 확정되면 `js/wbs-data.js`와 `docs/WBS.md`를 함께 갱신합니다.
- 비밀번호·토큰·환경 파일·실제 계정·운영 데이터는 포함하지 않습니다.

## 우선 확정할 항목

1. 생산부 회의 일정과 참여자
2. 생산부 요구사항의 우선순위와 완료 조건
3. 생산부 단계 완료 후 사업부 회의 일정
4. 사업부 단계 완료 후 기술개발부 회의 일정
