## ERP 외 작업
### 업데이트 안내 서비스
- erp-updatepage/compose.yaml: 호스트 8000 → 컨테이너 8080, 독립 프로젝트.
- /는 안내, /settings.html은 관리자 설정, /api/settings는 저장 API, /health는 상태 확인.
- HTTP Basic 인증. 관리자 비밀번호는 필수이지만 최소 길이 제한은 사용자 요청으로 제거했습니다.
- 제목 및 한국 시간 기준 완료 시각 설정, 카운트다운, 시간 초과 안내, 설정 영속 볼륨.
- 로컬 파일 설정은 HTML 다운로드, 웹 설정은 서버 저장 방식입니다.
- Compose는 env_file: ./.env로 직접 읽습니다. 숨김 .env의 NAS 누락으로 생성 오류가 발생했습니다.
- 대화 중 공개 /health 200, /settings.html 401 및 Basic 인증 헤더를 확인했습니다. 설정 페이지 인증 성공·실제 저장 완료는 확인되지 않았습니다.
- 자동 점검 전환/자동 ERP 복구 라우팅은 구현하지 않았습니다.
### 공용 오류 페이지
- tempchain-erp-error-pages에 공용 오류 페이지 묶음이 있습니다. 운영 포털의 최신 파일 적용 여부는 별도 확인합니다.
