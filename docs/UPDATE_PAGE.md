# 업데이트 안내 컨테이너

## Container Manager 등록

1. `/volume1/docker/erp-updatepage/.env`를 새로 만들고 외부에 공개하지 않습니다. 현재 저장소에는 복사용 `.env.example`이 없습니다.
2. `.env`의 `UPDATE_ADMIN_PASSWORD`에 관리자 비밀번호(길이 제한 없음)를 입력합니다. `UPDATE_ADMIN_USER`의 기본값은 `admin`입니다.
3. Container Manager에서 이 폴더를 프로젝트 경로로 지정하고 compose.yaml로 빌드·실행합니다.

- 안내 화면: http://서버주소:8000/
- 설정 화면: http://서버주소:8000/settings.html
- 관리자 이름/비밀번호는 .env에 지정한 값을 사용합니다.
- 외부에서 설정 페이지를 사용할 때에는 HTTPS 리버스 프록시를 통해 접속하세요. HTTP Basic 인증을 사용합니다.
- 기존 ERP 프로젝트와 별개이며 DB 연결이 없습니다. 호스트 8000 포트를 컨테이너 8080에 연결합니다.

## 설정과 보관

웹 설정에서 문구와 한국 시간 기준 예상 완료 시각을 지정하고 **저장하고 적용**을 누릅니다. 서버의 명명된 볼륨에 설정이 보관되어 재시작 후에도 유지됩니다. 이미 열린 안내 화면은 새로고침하면 변경 내용을 표시합니다.

시간 초과 시 작업 지연 안내로 전환하며 자동으로 서비스 복구를 선언하지 않습니다. 서버의 점검 페이지 전환 및 정상 서비스 복귀는 별도 설정입니다.

설정 화면을 로컬 파일로 열면 이전처럼 독립형 index.html 다운로드 방식으로 사용할 수 있습니다. 기본 index.html은 시간 미지정 상태입니다. 생성된 HTML은 로고·스타일·카운트다운을 내장합니다.

카드 상단 장식선, 하단 예상 시간 안내 문구, 다시 시도 버튼 및 INTERNAL OPERATIONS는 제거했습니다.

## 검증

- conda scott에서 verify.mjs 통과: 타이머 경계·시간 초과 전환·입력 유효성·HTML 삽입 방지. 실행 시 기본 index.html을 재생성합니다.
- server.test.mjs 통과: 설정 인증, 저장 보호, 공개 페이지 반영, 서버 재시작 후 설정 유지.
- docker compose config --quiet 통과. 컨테이너 이미지 빌드·실제 NAS 실행은 미수행입니다.
- 브라우저 시각 검증은 도구 초기화 오류로 미수행입니다.
## Container Manager 환경파일 처리

Compose 변수 보간 대신 env_file: ./.env로 기존 파일을 직접 읽습니다. NAS 프로젝트 폴더에도 .env가 있어야 합니다. 로컬 파일 존재는 NAS 동기화 완료를 보장하지 않습니다. 비밀번호 파일 복사나 변경은 수행하지 않았습니다.
