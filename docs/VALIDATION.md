재시작 시험에서 API가 DB 준비 전에 종료되는 문제를 발견해, 일시적인 연결 오류에만 최대 30초 재시도를 추가했습니다. 스키마/설정 오류를 무한 재시도하지 않습니다.

## 이미지 검사

고정 버전은 Node 24.21.0, Nginx 1.30.4, PostgreSQL 18.6입니다. Alpine 보안 패치를 빌드 중 적용하고 PostgreSQL의 권한 전환은 Alpine `su-exec`을 사용합니다.

Docker Scout의 **critical/high 범위** 검사에서 API·웹·조회 이미지는 발견 0건입니다. PostgreSQL은 원본 이미지 계층의 Go stdlib 1.24.6을 2 critical·20 high로 계속 보고했습니다. `--locations`가 가리킨 `/usr/local/bin/gosu`는 최종 컨테이너 파일시스템에서 삭제되어 존재하지 않으며, entrypoint가 `su-exec postgres`를 호출하는 것을 별도로 확인했습니다. 이 스캐너 결과를 0건으로 표시하지 않았습니다.

이 결과는 해당 시점의 지정 심각도 검사이며 모든 취약점이나 실제 NAS 환경의 보안을 보증하지 않습니다. 공식 이미지 설정 근거는 [Node](https://hub.docker.com/_/node), [Nginx](https://hub.docker.com/_/nginx), [PostgreSQL](https://hub.docker.com/_/postgres)을 참고합니다.
