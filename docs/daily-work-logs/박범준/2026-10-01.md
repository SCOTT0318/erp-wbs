## 오늘 완료한 업무

### 1. 관리자 데이터 관리 및 생산 업무 구분 개선

- 관리자 앱에 ERP 테이블 검색·페이지 조회·전체 필드 상세와 담당자·활동 이력 조회를 구현함. 비밀 정보는 가리고, 제한된 설명 수정과 미사용 자료 삭제는 연결 관계·재고·현재 버전을 검사하며 변경 사유와 변경 전 자료를 보존하도록 처리함.
- 자재·소형 제품의 입고 QC 판정을 기술개발부 업무로 분리함. 기술개발부 지정 승인자와 관리자만 판정하도록 API 권한을 적용하고, 생산부는 재고·실사 업무를 처리하도록 화면을 정리함.
- 생산 계획·불량/재작업을 생산관리 내부 탭으로 통합함. 컨테이너 출고·예약에 검색·전체 선택·해제를 지원하는 공통 개체 선택 화면을 추가함.

### 2. 개인 메모·알림·실시간 검색 구현

- 작성자만 조회·수정·삭제할 수 있는 개인 메모 API와 홈 메모 화면을 추가함. 관리자 데이터 조회에서도 개인 메모·개인 알림을 제외하고 메모 모달, 색상 선택, 입력 높이 자동 조절을 구현함.
- 관리자 알림 규칙에 업무·역할·부서·직급·실제 처리 권한·사용자 조건을 연결함. 업무 변경에 따른 중복 발송 방지와 개인 알림 조회·읽음·모두 읽음 처리를 추가함.
- 통합 검색을 입력 중 자동 조회하도록 개선하고 한글 조합 중에도 검색어를 반영함. 계정별 최근 검색과 결과 이동을 제공함.

### 3. 부서별 대시보드·일정 및 화면 정리

- 사업부·기술개발부 홈과 재고·실사, 생산 기준정보·개체 관리에 대시보드를 구성함. 홈은 해당 부서 전체 업무 일정을 모으고 개별 업무 화면은 관련 일정만 표시하도록 분리함.
- 신청 납기, 생산·입출고·반납 예정·실사·재작업과 챔버 예약·교정·샘플 보관·시험·QC 기록을 부서 달력에 연결함. 한국 시간의 월 경계와 기간 종료일을 처리하고 달력 오른쪽에 선택일 상세 목록을 제공함.
- 관리자 달력에 공통 한국 공휴일 데이터를 적용함. 탭 크기·위치, 요약 카드 높이·수직 중앙, 로고 심볼·글자, 사이드바 펼침 전환과 관리자 메뉴 위치를 통일함.
- 지정한 업무 설명 문구를 제거하고 QC 메뉴 아이콘을 변경함. 로그인 로고와 카드를 화면 좌우 반쪽의 가운데에 각각 배치함.

### 4. 부서 선택·프로필 권한을 서버에서 검증

- 서버가 최신 계정의 소속·활성·역할을 확인해 선택 가능한 업무 부서를 반환하도록 구현함. 일반 계정은 소속 부서만 사용하고 관리자·경영진만 다른 부서를 선택하도록 제한함.
- 부서 선택과 부서 달력 API에서 권한을 별도로 검사함. 브라우저 버튼·권한 표시를 변경하거나 다른 부서 ID를 직접 전송해도 서버 권한이 바뀌지 않도록 처리함.
- 내 정보 화면을 계정 정보 조회와 비밀번호 변경 중심으로 재구성함. 일반 계정의 이름·이메일·사진 변경 API도 차단하고 기존 관리자 계정 관리 기능은 유지함.

### 5. SSH 서버 배포 및 로컬 개발 DB 정리

- 승인된 SSH 서버에 API·웹·관리자 이미지를 배포함. 기존 DB·백업·점검 서비스와 설정을 보존하고 이전 앱 컨테이너를 롤백용으로 유지함. LAN 서비스와 진입 파일의 정상 응답을 확인함.
- 배포 DB의 실제 PostgreSQL 포트와 실행 중 API 연결이 모두 5432임을 확인함. DB는 내부 네트워크로 연결하며 호스트에 공개하지 않음.
- 로컬 개발 DB를 `tempchain-erp-local`, loopback 5432로 전환하고 기존 데이터·자격 증명을 보존함. 개발 앱 연결도 같은 포트로 맞추고 DB만 시작하는 실행 옵션을 추가함.
- 개발 실행기가 이미지·데이터 경로·포트·자격 증명을 검사한 DB만 재사용하도록 수정함. 동일 데이터 폴더의 중복 실행을 차단하고 이미 실행 중이던 DB는 개발 앱 종료 시 유지하도록 처리함.

## 이슈 및 확인 사항

- Windows 외부 백업 관련 기존 검사 실패가 남아 있어 전체 회귀 성공으로 기록하지 않음. 실제 운영 백업·복원은 이번 작업에서 수행하지 않음.
- 화면 검증은 격리 API 응답으로 수행함. 실제 NAS 인증과 실사용 데이터의 업무 수용 확인을 별도로 진행해야 함.
- 공개 DDNS의 NAS 프록시 목적지는 변경하지 않음. 서버 배포 완료와 공개 ERP 전환 완료를 구분함.
- 사업부 입고 신청 대상과 데이터로거 실시간 측정 연계는 기존 미확정 항목으로 남아 있음. 오늘 별도 QC 검수·VIP 시험 실적은 확인된 근거가 없어 추가하지 않음.
