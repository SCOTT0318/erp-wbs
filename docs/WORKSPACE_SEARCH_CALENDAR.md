# 업무 홈·통합 검색

## 화면
- 홈 제목은 WORKSPACE만 표시합니다. 사업부·기술개발부는 서비스 준비 중입니다 카드만 표시하며 생산부 현황은 유지합니다.
- 두 부서 거래처 메뉴는 App.vue에서 주석 처리했고 검색 바로가기에서도 숨겼습니다. 기존 경로·API·데이터와 관리자 거래처 관리는 유지합니다. 사이드바 내 정보는 제거하고 상단 프로필로 접근합니다.
- 경영진은 업무 부서 선택에서 숨기며 DB 부서·계정 정보와 관리자 관리는 유지합니다. 경영진 계정은 접근 가능한 생산부를 우선 선택하고, 없으면 다른 허용 부서로 연결합니다.
- 상단 프로필은 이름 직급님 형식이며 직급이 없으면 이름님으로 표시합니다.
- 상단 통합 검색의 기본 안내와 단축키 표시는 비웁니다. 두 글자부터 검색 결과를 열고 접근 가능한 전체 업무를 검색합니다. 2~80자, 입력 후 250ms 대기, 최대 20건을 표시합니다.
- 자재, 소형 제품, 컨테이너, 생산지시를 검색하며 현재 거래처 바로가기와 계정은 관리자에게 표시합니다. 서버의 부서별 조회 권한 검사는 유지합니다.
- 방향키로 결과를 선택하고 Enter로 이동합니다. Escape로 닫고 Ctrl/Cmd+K로 검색창에 초점을 이동합니다.
- 결과를 누르면 해당 화면의 상세 또는 정확히 해당 행을 표시합니다. 전체 목록/상세 닫기로 돌아갑니다.
- 검색 이력을 브라우저 저장소에 보관하지 않습니다.

## 검색 구현과 적용
- /api/search는 매 요청 사용자·부서·생산 조회 권한을 검사합니다. 삭제된 거래처를 제외합니다.
- PostgreSQL GIN 표현식 인덱스 5개가 두 글자 조각으로 한글 부분 문자열 후보를 좁힙니다. 일치 순서는 원문 부분 문자열로 재검사하며 %와 _도 문자로 취급합니다.
- pg_trgm 등 별도 확장 설치나 주기적 색인 동기화가 필요하지 않습니다. 데이터 변경 시 DB가 인덱스를 갱신합니다.
- schema v9 마이그레이션은 검색 함수·인덱스를 추가합니다. API 시작 시 기존 마이그레이션 잠금/트랜잭션을 사용하며 실제 운영 DB 적용은 이번 검증에 포함하지 않았습니다.
- 테스트 EXPLAIN은 작은 데이터에서 순차 검색을 끈 인덱스 사용 가능성 검사입니다. 실제 운영 데이터의 응답시간 측정 결과는 아닙니다.

## 월간 납기 일정
- 생산부의 주간 납기 영역을 월간 달력으로 교체했습니다. 이전 달·다음 달·오늘 이동과 일요일 시작 전체 주를 제공합니다.
- 날짜별 대기·진행 중 생산지시 건수와 월 합계를 표시합니다. 날짜 선택 시 5건씩 이전/다음 페이지로 조회하고 해당 생산지시 상세로 이동합니다.
- /api/work/calendar?month=YYYY-MM은 월간 집계, /api/work/calendar/day?date=YYYY-MM-DD&page=1은 선택일 목록입니다. 두 요청 모두 생산 조회 권한을 검사하며 완료·취소된 지시는 제외합니다.
- 1900~2100년 범위의 실제 날짜만 허용합니다. 느린 이전 요청은 무시하고 조회 실패 시 오류와 다시 조회를 표시합니다. 기존 업무 현황 API 응답 계약은 유지합니다.

## 대한민국 달력
- 토요일은 파랑, 일요일과 공휴일은 빨강으로 구분합니다. 설·추석·대체공휴일·선거일 이름을 표시합니다.
- 2026~2027년 공식 발표 자료를 내장했습니다. 키나 외부 통신 없이 동작하며 실시간 자동 연동은 아닙니다.
- 범위 밖 연도는 주말만 표시하고 자료 없음 안내를 제공합니다. 새 연도 및 추후 지정되는 임시공휴일은 korea-calendar.ts를 갱신해야 합니다.
- 날짜 기준은 Asia/Seoul이며 date-only 계산은 기기 시간대에 영향을 받지 않습니다.
- [한국천문연구원 달력자료](https://astro.kasi.re.kr/life/post/calendardata)
- [우주항공청 2027 월력요항 및 2026 공휴일 변경 안내](https://www.kasa.go.kr/prog/plcyBrf/brief/kor/sub01_01_04/view.do?plcyBrfNo=431)
- [특일정보 API](https://www.data.go.kr/data/15012690/openapi.do): 향후 실시간 연동 시 서비스키 필요.

## 기존 백업 호환성
인덱스만 추가하는 v9에서도 서명된 v8·v9 백업을 지원합니다. 체크섬·서명·테이블·건수·관리자·메타데이터 검사를 유지하고 v8 자료 복원과 검색 인덱스 재생성은 같은 트랜잭션에서 실행합니다. v7 이하와 미래 버전은 계속 거부합니다. 실제 운영 복원은 수행하지 않았습니다.

## 프로필 편집
사진 편집의 파일 업로드·기본 이미지를 같은 행에 배치하고 초기화를 확대/축소 옆으로 옮겼습니다. 긴 화면 안내는 삭제하고 방향키 조정 설명만 화면 읽기 도구용으로 유지합니다. 적용 후 사진 저장을 눌러야 저장되는 흐름은 같습니다.
